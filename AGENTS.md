# Instrucciones para agentes de LOS DUROS

Antes de trabajar en este repositorio o usarlo como brain, leer:
1. `brain/comment-rules.md`
2. `brain/brand-rules.md`
3. `brain/asset-registry.md`
4. `20-zion-autonomia-y-enforcement.md`
5. Los archivos `01–19` pertinentes al trabajo.

`20-zion-autonomia-y-enforcement.md` contiene instrucciones obligatorias de Nelson del 2026-10-10 sobre autonomia operativa, conversacion con Blaze, contexto, formatos y gate antes de enviar. Aplicar las correcciones especificas sin borrar antecedentes. En IG corto prevalecen dos emojis sobre el default general de uno.

Las instrucciones explicitas vigentes de Nelson prevalecen. Conservar aislamiento entre marcas. No publicar contenido ni contactar nuevos destinatarios fuera del alcance autorizado. No pedir de nuevo permiso para reparaciones necesarias ya autorizadas.

Al integrar este brain en ZION/BLAZE, incluir estos documentos en el mecanismo real de lectura/carga. Verificar version cargada y comportamiento; publicar en GitHub no acredita sincronizacion de VM ni activacion del worker. Informar cada estado con evidencia.

No crear infraestructura generica nueva para almacenar las reglas. Usar el mecanismo existente y las instrucciones aplicables del proyecto.
